# لَمّة: دليل النشر والتحديث

لعبة كروت مصرية (ضد الروبوت، تحدي النهارده، أونلاين مع الأصحاب) تتثبّت كتطبيق وتشتغل أوفلاين ضد الروبوت.

## الملفات
- `index.html`: اللعبة كلها (ملف واحد بدون مكتبات، ما عدا PeerJS اللي بتتحمّل عند اللعب الأونلاين بس)
- `manifest.webmanifest` + `sw.js` + `icons/`: التثبيت كتطبيق والعمل أوفلاين
- `make_icons.py`: يولّد الأيقونات (اختياري)

## تحديث نسخة موجودة على GitHub
1. استبدل `index.html` و`manifest.webmanifest` و`sw.js` و`README.md` بالجديد (الأيقونات ما اتغيرتش).
2. اعمل Commit وPush. GitHub Pages / Cloudflare Pages بينشروا لوحدهم.
3. المستخدمين اللي مثبّتين التطبيق هيظهرلهم شريط «في نسخة جديدة» ويدوسوا «حدّث».
4. **أي تعديل بعد كده:** غيّر رقم `CACHE` في أول `sw.js` (النسخة دي `lamma-v5`، والجاية `lamma-v6`) عشان التحديث يوصل.

## تجربة محلية
```
python3 -m http.server 8080
```
افتح `http://localhost:8080`. التثبيت والـ service worker بيشتغلوا على `https` أو `localhost` بس.

## القواعد اللي اتطبّقت في الشاشة والتحكم
- **الموبايل أولاً:** الأماكن التلاتة أعمدة، والكروت فيها مصغّرة بالقوة الحالية بعد القدرات (أخضر = زادت، أحمر = قلّت). ضغطة على الكارت أو ضغطة طويلة تفتح تفاصيله.
- **تصميم هادي بدون أيقونات:** الشعار هو كلمة «لَمّة» بس. الكروت بالرقم الكبير ولون نوعها (مكان، سند، مواجهة، قوة، مفاجأة) بدل الإيموجي، عشان تظهر نفس الشكل على كل الأجهزة والمتصفحات.
- **ضغطة تختار وضغطة تأكّد:** دوس على الكارت، ثم المكان، ثم دوس على نفس الكارت تاني عشان يتلعب. الكارت بيظهر في المكان قبل التأكيد، وبيظهر مكسبك المتوقع (+N) على كل مكان. ضغطة على المكان تاني بتلغي الاختيار، وضغطة على الكارت قبل اختيار المكان بتشيله.
- **العدّاد (أونلاين فقط):** مفيش أي وقت ولا لعب تلقائي طول ما محدش لعب. أول ما حد يلعب بيبدأ عدّاد 15 ثانية للتاني (حلقة متحركة، وتحويل للأحمر وهزّة آخر 5 ثواني). لو خلص بيتلعب له كارت عشوائي. اللعب ضد الروبوت مفيهوش عدّاد خالص.
- **صورة الخصم:** رسمة روبوت ضد الروبوت، وأونلاين أول حرف من اسم اللاعب بلونه.

## الأمان وأفضل الممارسات
- الكروت اللي بتيجي من الشبكة بتتعمل من بيانات محلية بالـ id فقط، والأسماء بتتعرض كنص، وكل حقل بيتفحص ويتقصّ (مختبر ضد رسائل خبيثة).
- المضيف هو الحكم: بيتحقق من كل حركة، والضيف مش بيشوف كروت المضيف قبل الكشف.
- Content-Security-Policy، وwake lock بيمنع انطفاء الشاشة، واهتزاز خفيف، وتنقل بلوحة المفاتيح، وaria-labels، واحترام `prefers-reduced-motion`، وأزرار بمساحة لمس ≥ 44px، ومساحات آمنة للنوتش.
- لو الإنترنت قطع في نص لعب أونلاين بتظهر رسالة، ولو التبويب اتقفل الأوضة بتتقفل.

## النشر
**Cloudflare Pages:** dash.cloudflare.com ← Workers & Pages ← Create ← Pages ← Upload assets ← اسحب الملفات.
**GitHub Pages:** Settings ← Pages ← Deploy from branch.
**Netlify Drop:** اسحب الفولدر على app.netlify.com/drop.

## تحويله لتطبيق متجر
1. انشره على `https` أولاً.
2. pwabuilder.com ← الصق الرابط ← Package for stores ← Android (APK للتجربة وAAB للمتجر).
3. Google Play محتاج حساب مطوّر (رسم لمرة واحدة، راجع المبلغ الحالي). **احتفظ بملف التوقيع** وإلا مش هتقدر تحدّث التطبيق.
4. App Store: محتاج Mac وحساب Apple Developer مدفوع، وآبل ممكن ترفض تطبيق هو مجرد غلاف لموقع. التثبيت من Safari أسهل.

## اللعب الأونلاين: حدوده
الاتصال مباشر بين الجهازين (PeerJS)، وبيبدأ عن طريق سيرفر PeerJS العام المجاني بدون ضمان استمرار. على بعض شبكات الموبايل أو الشركات ممكن يفشل (محتاج TURN). لو اللعبة كبرت: PeerServer خاص بيك أو Cloudflare Durable Objects، وده كمان بيفتح باب لوحة الترتيب والأوضات العامة.

## مقترحات لتخلّي الناس تتمسك باللعبة
**موجود دلوقتي:** مستويات وخبرة، سلسلة أيام متتالية، ١١ إنجاز، ألوان للاعب بتتفتح بالمستوى، رسائل سريعة نصية أونلاين، تحدي يومي، مشاركة النتيجة، رابط دعوة للأوضة.
**الخطوة الجاية (بالأولوية):**
1. **سيرفر خفيف + حساب:** حفظ التقدم على أكتر من جهاز، ولوحة ترتيب يومية وأسبوعية. (أكبر أثر على الرجوع اليومي).
2. **أصدقاء ولمّات:** قايمة أصحاب، دعوة بضغطة، وفرق ("لمّات") بترتيب جماعي.
3. **إشعارات:** «تحدي النهارده جاهز» و«سلسلتك هتضيع النهارده» (Web Push بعد وجود السيرفر).
4. **مواسم أسبوعية:** حدث خاص (رمضان، موالد، كاس أمم) بكروت وأحداث مؤقتة وجوايز شكلية.
5. **تجميع كروت:** كروت نادرة بتتفتح بالمستوى وتتحط في «ديك» يختاره اللاعب قبل الجولة (عمق استراتيجي أكبر).
6. **ترتيب تنافسي:** درجات (برونز ← ذهب) أونلاين بمطابقة على المستوى.
7. **تحدّيات خاصة:** قواعد غريبة بتتغير كل يوم (مثلا «ممنوع التبديل» أو «كل الأحداث في القهوة»).
8. **قياس:** أحداث تحليلات بسيطة (بدء جولة، إنهاء، انسحاب، رجوع بعد يوم/٧ أيام) علشان تعرف فين الناس بتسيب اللعبة.
